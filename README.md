# Gedeelde webcursussen

Deze repository is de enige bron voor alle cursusinhoud: `docs/`, oefeningen met
startcode en oplossingen, `src/`, quizzen en `static/`. De eigen `sidebars.ts`
gebruikt autogeneratie vanaf `docs/`, zodat de broncursus alle onderwerpen bevat,
ook wanneer er nieuwe bijkomen.

Afzonderlijke cursusrepositories bevatten alleen hun Docusaurus-configuratie,
sidebars, npm-opdrachten, README, workflow en een Git-submoduleverwijzing naar
deze monorepo. De submodule heet `course-material/` en legt per cursus een
specifieke monorepo-commit vast. Ze houden geen eigen kopieën van lessen,
componenten, assets, buildscripts of dependencies bij.

## Installeren en bouwen

Gebruik Node.js 22 of nieuwer:

```bash
npm ci
npm test
npm run assemble   # alle onderwerpen samenstellen
npm start          # alle onderwerpen lokaal bekijken
npm run build      # volledige broncursus bouwen in .course/build/
npm run serve      # bestaande build bekijken
```

Een andere cursus samenstellen of bouwen:

```bash
node scripts/course.cjs --course ../webontwikkeling-docusaurus assemble
node scripts/course.cjs --course ../webontwikkeling-docusaurus build
node scripts/course.cjs --course ../webontwikkeling-docusaurus start --port 3001 --no-open
```

`serve` en `clear` werken op de bestaande `.course/`. `assemble`, `start`, `build`
en `typecheck` maken eerst een nieuwe assembly. Stop en herstart de ontwikkelserver
na wijzigingen in de broninhoud of cursusconfiguratie. De server bekijkt een kopie;
wijzigingen in die gegenereerde kopie worden bij de volgende assembly vervangen.

## Selectie via Docusaurus

`scripts/assemble-course.cjs` laadt de echte TypeScript/JavaScript-configuratie
(ook een async configuratiefunctie) en de `sidebarPath` uit het classic-preset.
Het gebruikt de Docusaurus-parser voor front matter, document-ID's en
sidebar-notaties. Dezelfde vastgelegde Docusaurus-versie wordt gebruikt bij het
samenstellen en het bouwen.

Ondersteunde selecties:

- Een document-ID als string, een `doc`-item of een `ref`-item.
- Geneste categorieën, verkorte categorie-notaties en `link: {type: 'doc', id: ...}`.
- `autogenerated` met een map onder de gedeelde `docs/`, of `.` voor alle onderwerpen.
- `customFields: {course: {extraDocs: ['some/document']}}` voor extra pagina's
  buiten de sidebar.

Het classic-preset kan met `docs.path` een andere bronmap kiezen en met
`docs.include`/`docs.exclude` de beschikbare Markdown-bestanden beperken.
Zonder `sidebarPath`, of met `sidebarPath: false`, worden alle toegelaten documenten
geselecteerd. Nummerprefixen en front matter `id`/`parse_number_prefixes` volgen
Docusaurus. De scripts ondersteunen één docs-instantie via het classic-preset.

De configuratiebestanden blijven in de cursusrepository. Rootmodules
(`.ts`, `.js`, `.cjs`, `.mjs`, `.mts`, `.cts`, `.json`) en optionele helpers in
`config/` worden meegenomen, zodat relatieve imports blijven werken. Gebruik
relatieve configuratiepaden, bijvoorbeeld `sidebarPath: './sidebars.ts'` en
`customCss: './src/css/custom.css'`. Externe pakketten horen in deze monorepo.

## Gegenereerde uitvoer

De assembly schrijft naar de genegeerde map `.course/` van de doelcursus:

- Alleen geselecteerde lessen worden gekopieerd en als Docusaurus-pagina gebouwd.
- Bij geselecteerde oefeningen worden ook startcode en oplossingen gekopieerd;
  `build-exercises.cjs` maakt er downloads van voor zowel ontwikkeling als productie.
- Gedeelde React-componenten, CSS, statische assets, afbeeldingen in `docs/` en
  MDX-partials worden meegeleverd. Deze assets worden bewust gedeeld, ook wanneer
  componenten er dynamisch naar verwijzen.
- `starter/`, `solution/` en `node_modules/` leveren geen zelfstandige lespagina's.
- `.assembled-course.json` bevat de geselecteerde documentpaden en oefeningen.
- `.course/build/` bevat de productiebuild en is de publicatiemap van de workflow.

Links naar andere lessen worden niet gevolgd om de selectie uit te breiden.
Selecteer zulke lessen expliciet in de sidebar of `extraDocs`. De ingestelde
Docusaurus-controles rapporteren ontbrekende links. Een selectie met een onbekend
ID of een lege autogenerated-map faalt voordat de vorige assembly wordt vervangen.
Een nieuwe assembly verwijdert eerder geselecteerde pagina's en oude downloads.

De enige plaats om inhoud te wijzigen is deze monorepo. Voor een nieuwe cursus
kopieer je de configuratie en buildsetup van `webontwikkeling-docusaurus`, pas je
de identiteit/navbar aan en kies je de onderwerpen in `sidebars.ts`.

De workflows installeren via `npm ci`, bouwen pull requests zonder publicatie en
publiceren alleen een push of handmatige run op `main`. Een cursusworkflow haalt
de vastgelegde submodule-commit op met `submodules: recursive`.

Een cursus neemt nieuwe inhoud pas over wanneer de submoduleverwijzing wordt
bijgewerkt. Voer in de cursusrepository uit:

```bash
git submodule update --remote --checkout course-material
npm run setup
npm ci --prefix course-material
npm run build
git add course-material
git commit -m "Update shared course material"
```

Gebruik tijdens deze update rechtstreeks `npm ci --prefix course-material`;
`npm run setup` herstelt de momenteel vastgelegde submodule-commit.

Publiceer de monorepo-commit voordat je de bijbehorende cursusverwijzing
publiceert, zodat andere checkouts en CI die commit kunnen ophalen. De
submodule kan ook een oudere commit vastleggen voor een eerdere cursusversie.
Voor de volledige clone- en updateprocedure zie de README van de cursus.

# Pizza Builder: client

Start eerst de bijhorende server. Gebruik Node.js 22.12 of nieuwer.

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. Dit is de origin die in de server toegelaten wordt via CORS. De API draait op `http://localhost:3000`.

Controleer de types met `npm run typecheck` en bouw met `npm run build`.

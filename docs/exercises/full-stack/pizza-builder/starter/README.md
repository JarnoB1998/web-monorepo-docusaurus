# Starterproject

Dit project bevat de HTML en CSS voor de frontend. Werk de functionaliteit uit in `src/main.ts`. Maak zelf de types en eventuele modules aan volgens de opgave. De server bouw je in een apart project, of neem je over uit de voorgaande oefening.

Gebruik Node.js 22.12 of nieuwer.

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. Typecontrole: `npm run typecheck`. Productiebuild: `npm run build`.

# reiskosten-server

Gebruik Node.js 24.12.0 of nieuwer. Kopieer `.env.example` naar `.env` en vul je eigen gegevens in.

```bash
npm install
npm start
```

Typecontrole: `npm run typecheck`. De API draait op `http://localhost:3000`. De gegevens staan in een array en verdwijnen wanneer je de server stopt.
